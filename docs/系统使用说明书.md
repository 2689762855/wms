# 库存管理系统 (WMS) — 使用说明书

## 1. 登录

打开浏览器访问 `http://localhost:3001`，输入管理员账号和密码登录。

> 首次运行时自动创建管理员账号，用户名固定为 `admin`，密码随机生成并在启动窗口中显示。**密码只显示一次，请务必记下。**

---

## 2. 仪表盘

登录后默认进入仪表盘，展示：

- 库存总览（商品数、仓库数、库存总量）
- 最近出入库趋势图
- 库存预警统计

---

## 3. 仓库管理

**路径**：侧边栏 → 仓库管理

- 点击「新建仓库」添加仓库，填写名称和地址
- 点击仓库名称进入库位管理
- 在库位管理页面可为仓库添加库位（如 A-01、B-03）
- 每个库位自动生成二维码，可打印后贴在货架上

---

## 4. 商品管理

### 4.1 商品分类

**路径**：侧边栏 → 商品管理 → 商品分类

- 支持无限层级分类树
- 可新建、编辑、删除分类
- 删除前需确保分类下无商品

### 4.2 商品列表

**路径**：侧边栏 → 商品管理 → 商品列表

- 点击「新建商品」添加 SKU
- 必填：SKU 编码、商品名称、单位
- 选填：规格型号、条码、分类、安全库存、成本价、售价
- 安全库存：当某仓库库存低于此值时触发预警

---

## 5. 库存管理

### 5.1 库存查询

**路径**：侧边栏 → 库存管理 → 库存查询

- 按仓库筛选，查看每个商品在各库位的实时库存
- 支持按商品名称/SKU 搜索

### 5.2 库存流水

**路径**：侧边栏 → 库存管理 → 库存流水

- 查看所有库存变动记录
- 每条记录显示：商品、仓库、变动数量、变动前后数量、类型、关联单据

---

## 6. 入库管理

**路径**：侧边栏 → 入库管理

### 6.1 创建入库单

1. 点击「新建入库」
2. 选择入库仓库和库位
3. 填写供应商（可选）
4. 添加商品：搜索商品 → 输入数量 → 指定库位
5. 保存草稿或直接确认入库

- **草稿**：未确认的入库单不更新库存，可继续编辑
- **确认**：商品入库，库存增加，生成库存流水

### 6.2 入库单列表

- 查看所有入库单，支持按仓库/状态/日期筛选
- 点击单号查看详情

---

## 7. 出库管理

**路径**：侧边栏 → 出库管理

操作流程与入库类似：

1. 新建出库单 → 选择仓库和库位 → 填写领用人
2. 添加商品并输入数量
3. 确认后库存扣减

> 确认出库时会校验库存是否充足，不足时提示并阻止出库。

---

## 8. 调拨管理

**路径**：侧边栏 → 调拨管理

用于在不同仓库之间转移商品库存。

### 8.1 调拨流程

```
创建调拨单（草稿）→ 提交审批（待审批）→ 审批通过/驳回
```

1. 点击「新建调拨」→ 选择调出仓库和调入仓库
2. 添加调拨商品和数量
3. 保存草稿后可「提交审批」
4. 审批人（仓库管理员及以上角色）可「通过」或「驳回」
5. 审批通过后自动完成库存转移（调出仓扣减、调入仓增加）

### 8.2 状态说明

| 状态 | 说明 |
|------|------|
| 草稿 | 可编辑，未提交 |
| 待审批 | 已提交，等待审批人处理 |
| 已通过 | 审批通过，库存已转移 |
| 已驳回 | 审批驳回，库存不变 |

---

## 9. 盘点管理

**路径**：侧边栏 → 盘点管理

### 9.1 创建盘点任务

1. 点击「新建盘点」→ 选择仓库
2. 可指定盘点库位（不指定则盘点整个仓库）
3. 系统根据当前库存自动生成盘点清单

### 9.2 主任务与子任务

- **主任务**：统计盘点进度和结果
- **子任务**：分配给不同人员，按库位独立盘点

### 9.3 执行盘点

1. 进入盘点任务 → 逐项核对实际数量
2. 输入实盘数量，系统自动计算差异
3. 有差异的商品标记为「异常」
4. 负责人审核异常，填写审核备注
5. 审核通过后差异自动调整库存

---

## 10. 库存预警

**路径**：侧边栏 → 库存预警

- 按仓库 × 商品维度展示库存状态
- 当前库存 < 安全库存时显示预警
- 可筛选特定仓库查看

---

## 11. 报表统计

### 11.1 出入库报表

**路径**：侧边栏 → 报表统计 → 出入库报表

- 按时间段统计各仓库的入库/出库总量
- 可视化图表展示趋势

### 11.2 周转率报表

**路径**：侧边栏 → 报表统计 → 周转率报表

- 按商品统计库存周转率
- 帮助识别滞销和畅销商品

---

## 12. 系统设置

### 12.1 用户管理

**路径**：侧边栏 → 系统设置 → 用户管理

三种角色：

| 角色 | 权限 |
|------|------|
| 超级管理员 | 全部权限，可管理用户 |
| 仓库管理员 | 管理所属仓库，可审批调拨 |
| 操作员 | 日常出入库、盘点操作 |

- 新建用户时填写用户名、密码（6-128 位）、角色、所属仓库
- 可修改用户信息和重置密码

### 12.2 客户管理

**路径**：侧边栏 → 系统设置 → 客户管理

- 创建客户账号，客户可登录 `/stock` 查询库存
- 可限制客户只能查看指定仓库的库存
- 客户登录使用独立入口和独立 JWT 密钥

---

## 13. 移动端操作

**访问地址**：`http://你的IP:3001/m`

5 个底部 Tab：

| Tab | 功能 |
|-----|------|
| 入库 | 入库单列表 → 新建入库 → 入库详情 |
| 出库 | 出库单列表 → 新建出库 → 出库详情 |
| 盘点 | 盘点任务列表 → 执行盘点 |
| 转移 | 库位间库存转移（同一仓库内） |
| 库存 | 库存查询 |

### 扫码功能

- 入库/出库/盘点/转移均支持条码/二维码扫码
- 点击扫码按钮 → 摄像头扫描商品条码 → 自动填入
- Android APP 使用原生扫码（华为/小米/OPPO 均支持）
- 原生扫码失败时自动切换为网页扫码

### APK 安装

- APK 文件在 `server/apk/app-v1.0.apk`
- 安装后首次打开，点击登录页齿轮图标设置服务器地址
- 地址格式：`http://你的电脑IP:3001`

---

## 14. 客户自助查询

**访问地址**：`http://你的IP:3001/stock`

- 使用管理员创建的客户账号登录
- 可查看被授权仓库的实时库存
- 仅查看权限，无法操作

---

## 15. 数据备份

- 所有数据存储在 `server/prisma/dev.db`（SQLite 单文件）
- 备份方法：复制 `dev.db` 到安全位置
- 恢复方法：将备份文件覆盖回原位置
- **建议每天备份一次**

---

## 16. 常见问题

**Q: 入库确认后数量不对怎么办？**
A: 可创建盘点任务调整库存，或新建出库单冲销。

**Q: 调拨审批后库存没变化？**
A: 检查调拨单状态是否为「已通过」，只有审批通过才会转移库存。

**Q: 商品搜索不到？**
A: 先在「商品管理 → 商品列表」中确认商品已创建。搜索支持 SKU 和名称模糊匹配。

**Q: 移动端扫码没反应？**
A: 确保浏览器已授予摄像头权限。Android APP 优先使用原生扫码，失败会自动切换。

**Q: 如何多人同时使用？**
A: 启动服务后局域网内其他电脑通过 `http://服务器IP:3001` 访问，各自登录不同账号操作。

**Q: 库存流水能删除吗？**
A: 不能。库存流水是审计日志，不可修改或删除。
