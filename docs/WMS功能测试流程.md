# WMS 库存管理系统 — 功能测试流程

> 测试环境：http://localhost:5173
> 默认账号：`admin` / `admin123`
> 当前数据：主仓库 + 4 个商品（可湿水面纸/铝合金/面包/矿泉水）

---

## 测试前准备

1. 打开浏览器访问 http://localhost:5173
2. 使用账号 `admin` 密码 `admin123` 登录
3. 浏览器按 F12 打开开发者工具 → Console 面板，观察是否有红色报错
