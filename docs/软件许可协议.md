# 库存管理系统（WMS）软件许可协议

**协议编号：** WMS-EULA-2026
**生效日期：** 以购买/交付日期为准

---

## 一、定义

- **"软件"**：指库存管理系统（WMS）及其所有组成部分，包括但不限于后端服务程序、前端界面、数据库脚本、API 接口、文档及使用说明书。
- **"许可方"**：软件的开发者和版权所有者（以下简称"甲方"）。
- **"被许可方"**：购买或获得软件使用许可的个人、企业或其他组织（以下简称"乙方"）。
- **"授权范围"**：本协议第三条约定的具体使用权限。

---

## 二、知识产权声明

1. 本软件的全部源代码、界面设计、文档内容的著作权归甲方所有。
2. 本软件使用的开源组件（React、Express、Prisma、Ant Design 等）遵循其各自许可协议（MIT / BSD / Apache 2.0），甲方已确认无 GPL 等传染性许可限制。
3. 乙方不得移除、修改软件中的版权声明、许可标识或知识产权标记。

## 三、授权许可

### 3.1 许可类型

| 许可类型 | 使用范围 | 价格参考 |
|---------|---------|---------|
| **单机版** | 1 台服务器部署，不限用户数 | — |
| **多机版** | 不超过 N 台服务器部署（N 按购买约定） | — |
| **源码授权** | 获得完整源代码，可自行修改和二次开发 | — |
| **SaaS 托管** | 甲方提供云端部署和运维服务 | — |

具体许可类型以购买时签订的订单或发票为准。

### 3.2 许可范围

在许可类型范围内，乙方可以：

1. 在授权的服务器上安装、运行本软件；
2. 创建本软件的备份副本（用于数据安全目的）；
3. 根据自身业务需要配置软件参数、录入业务数据；
4. 将软件用于乙方自身的仓储管理业务。

### 3.3 许可限制

乙方不得：

1. 将软件转让、转租、转许可给第三方使用（除非获得甲方书面同意）；
2. 对软件进行逆向工程、反编译或反汇编（源码授权除外）；
3. 将软件用于提供第三方仓储管理服务（SaaS 转售），除非获得甲方书面同意；
4. 去除、规避软件中的技术保护措施或许可验证机制。

## 四、交付与部署

1. 甲方在收到乙方付款后 **7 个工作日内** 完成软件交付。
2. 交付物包括：软件程序包、部署文档、使用说明书。
3. 甲方可提供有偿部署服务，具体费用另行协商。
4. 乙方自行部署的，甲方提供 **30 天免费远程技术支持**（部署问题咨询）。

### 5.1 免费服务（交付后 30 天内）

- 软件使用培训（远程）
- Bug 修复（软件本身缺陷）

## 六、数据与隐私

1. **数据所有权**：乙方使用本软件产生的所有业务数据（商品、库存、出入库记录等）归乙方所有。
2. **数据安全**：甲方不会访问、收集、存储或分析乙方的业务数据。
3. **数据导出**：乙方有权随时导出自己的全部业务数据（支持 Excel / CSV 格式）。
4. **SaaS 模式**：如乙方选择甲方托管服务，甲方承诺：
   - 数据存储在乙方指定的服务器或甲方的安全服务器上；
   - 不会将乙方数据提供给任何第三方；
   - 服务终止后 30 天内提供完整数据导出，并删除服务器上的乙方数据。

## 八、违约与终止

1. 乙方违反本协议第三条（许可限制）的，甲方有权立即终止本许可，且已付费用不予退还。
2. 甲方有权在乙方逾期付款超过 **30 日** 后暂停技术支持服务。
3. 协议终止后，乙方应在 **15 日内** 停止使用本软件并删除所有副本（含备份）。
4. 协议终止不影响第六条关于数据所有权的约定——乙方仍可导出自己的业务数据。
